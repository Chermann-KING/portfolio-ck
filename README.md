## 🛠️ Stack Technique

### Frontend

- **Next.js 15.3.1** - Framework React avec App Router
- **React 19** - Bibliothèque UI avec Server Components
- **TypeScript 5** - Typage statique pour la robustesse
- **Tailwind CSS 3** - Framework CSS utility-first
- **Lucide React** - Icônes vectorielles modernes

### Outils de développement

- **ESLint** - Analyse statique du code
- **PostCSS** - Traitement des styles CSS
- **Geist Font** - Police système optimisée

### Architecture

```
src/
├── app/                    # App Router (Next.js 15)
│   ├── blog/              # Pages blog avec filtrage
│   ├── contact/           # Formulaire de contact
│   ├── legal/             # Pages légales
│   ├── projects/          # Portfolio projets
│   └── resume/            # CV en ligne
├── components/            # Composants réutilisables
│   ├── ui/               # Composants UI de base
│   └── sections/         # Sections métier
├── lib/                  # Utilitaires et données
└── types/               # Définitions TypeScript
```

## 🚀 Installation & Développement

### Prérequis

- **Node.js** 18.0+
- **npm** ou **yarn** ou **pnpm**

### Installation

```bash
# Cloner le repository
git clone https://github.com/hermann-moussavou/portfolio-ck.git
cd portfolio-ck

# Installer les dépendances
npm install
# ou
yarn install
# ou
pnpm install
```

### Développement

```bash
# Lancer le serveur de développement
npm run dev
# ou
yarn dev
# ou
pnpm dev

# Le site sera accessible sur http://localhost:3000
```

### Build de production

```bash
# Créer le build optimisé
npm run build

# Démarrer en production
npm run start
```

### Linting

```bash
# Vérifier le code
npm run lint

# Corriger automatiquement
npm run lint --fix
```
